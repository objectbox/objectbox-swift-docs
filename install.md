# Install ObjectBox Swift

ObjectBox Swift is available as a:

* CocoaPods pod
* Swift Package

To add it to your project, see the [instructions in the README](https://github.com/objectbox/objectbox-swift?tab=readme-ov-file#add-objectbox-to-your-project) file of the objectbox-swift repository.
